### HTML:
- HTML (HyperText Markup Language) is the most basic building block of the Web.
-  It defines the meaning and structure of web content.
- "Hypertext" refers to links that connect web pages to one another, either within a single website or between websites. 
- Links are a fundamental aspect of the Web. By uploading content to the Internet and linking it to pages created by other people, you become an active participant in the World Wide Web.
HTML uses "markup" to annotate text, images, and other content for display in a Web browser. HTML markup includes special "elements" such as :
`<head>`, `<title>`, `<body>`, `<header>`, `<footer>`, `<article>`, `<section>`, `<p>,` `<div>`, `<span>`, `<img>`, `<aside>`, `<audio>`, `<canvas>`, `<datalist>`, `<details>`, `<embed>`, `<nav>`, `<search>`, `<output>`, `<progress>`, `<video>`, `<ul>`, `<ol>`, `<li>` 
and many others.
- An HTML element is set off from other text in a document by "tags", which consist of the element name surrounded by `< and >`. 
- The name of an element inside a tag is case-insensitive. That is, it can be written in uppercase, lowercase, or a mixture. For example, the `<title>` tag can be written as `<Title>`, `<TITLE>`, or in any other way. However, the convention and recommended practice is to write tags in lowercase.


### CSS:
- CSS (Cascading Style Sheets) is a stylesheet language used to describe the presentation of a document written in HTML or XML.
- CSS is used to define styles for the layout, fonts, colors, and other aspects of a web page's appearance.
- CSS is designed to enable the separation of presentation and content, making it easier to maintain sites. This is achieved by separating the presentation rules from the content, making it easier to change the look of a site without having to change the content.

##### 1. CSS Selectors:
- CSS selectors are used to "find" (or select) the HTML elements you want to style.
- CSS selectors are patterns used to select the elements you want to style. They are used in CSS rules to specify which HTML elements the rule should apply to.
- There are several types of CSS selectors, including:
a. id Selector:
- The id selector uses the id attribute of an HTML element to select a specific element.
- The id of an element is unique within a page, so the id selector is used to select one unique element!
- To select an element with a specific id, write a hash (#) character, followed by the id of the element.
```
#para1 {
  text-align: center;
  color: red;
}
```

### JavaScript:
- JavaScript is a programming language that allows you to implement complex features on web pages.
- It is a client-side scripting language, which means that it runs in the user's web browser
- JavaScript can be used to create interactive effects within web browsers, such as form validation, dynamic content updates, animations, and more.
- JavaScript is a versatile language that can be used for both front-end and back-end development.
- JavaScript is often used in conjunction with HTML and CSS to create dynamic and interactive web pages.
